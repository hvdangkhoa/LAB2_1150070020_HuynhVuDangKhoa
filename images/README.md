# DANH SÁCH ẢNH MINH CHỨNG CẦN CHỤP - LAB 2

Thư mục này dùng để lưu trữ các hình ảnh chụp màn hình minh chứng kết quả thực hành của sinh viên (để nộp kèm báo cáo hoặc hiển thị trong README).

> **Lưu ý theo quy định thực hành**: Không sử dụng hình ảnh giả lập. Sinh viên chạy trực tiếp các giao diện trên máy tính và chụp ảnh màn hình lưu vào thư mục này với tên tệp tương ứng dưới đây:

| Tên tệp ảnh | Nội dung cần chụp |
| :--- | :--- |
| `01_frm_Menu.png` | Cửa sổ Menu chính khi khởi chạy ứng dụng (`week_02.frm_Menu`) |
| `02_frm_DES_Encrypt.png` | Form `frm_DES` sau khi nhập Plaintext và bấm nút **Encrypt** |
| `03_frm_DES_WrongKey.png` | Thông báo lỗi khi xóa bớt ký tự khóa DES (còn 4 ký tự) hoặc lỗi sai khóa khi giải mã |
| `04_frm_TripleDES.png` | Form `frm_TripleDES` sau khi mã hóa câu văn bản mẫu với khóa 24 byte |
| `05_frm_AES_Login_Encrypt.png` | Form `frm_AES` sau khi Register, Login thành công (ô Ticket hiện chuỗi HEX 32 ký tự) và đã Encrypt |
| `06_frm_RC4_BBF3.png` | Form `frm_RC4` sau khi nhập Plaintext `"Plaintext"` và Key `"Key"`, ô Ciphertext hiện chuỗi HEX chuẩn `BBF316E8D940AF0AD3` |
| `07_frm_Twofish.png` | Form `frm_Twofish` sau khi bấm **Generate IV** (16 byte HEX) và bấm **Encrypt** |
| `08_frm_AES_CTR.png` | Form `frm_AES_CTR` sau khi bấm **Generate Key**, **Generate Nonce** và bấm **Encrypt** |
| `09_frm_LichSu.png` | Form `frm_LichSu` hiển thị bảng dữ liệu các dòng thao tác từ SQL Server |
| `10_ssms_result.png` | Ảnh chụp màn hình SSMS khi thực thi tệp `03_Kiem_Tra_Du_Lieu.sql` |
| `11_python_gui.png` | Giao diện đồ họa Tkinter của ứng dụng Python `aes_cbc_gui.py` |
| `12_python_selftest.png` | Dòng lệnh Command Prompt chạy lệnh `py aes_cbc_gui.py --self-test` in ra `SELF-TEST OK` |
